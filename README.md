# OrbitalScope

A production-oriented platform for ingesting, validating, processing,
and exploring publicly available space-object data.


## Project goals

OrbitalScope aims to provide:

- Automated ingestion of public space-object datasets.
- Data validation and normalization.
- A REST API for querying orbital object information.
- Interactive visualizations and statistical analysis.
- A reproducible, containerized, and cloud-ready architecture.

## Current status

The project is currently in its initial design and research phase.
